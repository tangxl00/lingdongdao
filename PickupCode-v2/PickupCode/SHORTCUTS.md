# 快捷指令配置指南（SHORTCUTS.md）

配合《取件码灵动岛 App》使用：收到快递取件短信后，由「快捷指令自动化」自动提取取件码并唤起 App，在灵动岛展示。**目标读者：普通 iPhone 用户，无需技术背景，按步骤照做即可。**

前提：iPhone 已安装"快捷指令"App（系统自带）；取件码 App 已按 README 第一章安装到手机。

---

## 一、7 步配置流程

### 步骤 1 · 打开快捷指令 App

在桌面找到并打开 **快捷指令** App。

### 步骤 2 · 创建个人自动化

1. 点击底部 **自动化** 标签。
2. 点击右上角 **`+`**（新建自动化）。
3. 选择 **创建个人自动化**。

### 步骤 3 · 设置触发条件

1. 向下滚动，选择 **信息**。
2. 在"收到信息时"页面：
   - **信息包含**：输入 `取件码`（可再追加 `驿站`、`丰巢`、`快递柜` 等关键词，逗号分隔）。
   - **发送人**：选择 **任何人**（确保所有快递短信都能触发）。
3. 点击右上角 **下一步**。

> 建议策略：至少包含"取件码"即可覆盖 90% 以上场景；可根据自己常收的短信类型补充关键词。

### 步骤 4 · 添加提取取件码操作

1. 点击 **添加操作**。
2. 搜索并选择 **获取文本**（快捷指令会自动使用短信内容作为输入）。
3. 再次点击 **添加操作**。
4. 搜索并选择 **匹配文本**。
5. 在"模式"中输入正则表达式（覆盖数字、横杠及字母数字混合取件码）：

   ```
   取件码[：:]?\s*([A-Za-z0-9\-]+)
   ```

   > 提示：若短信中的取件码仅含纯数字或横杠，上述正则可正常提取；若含字母也一并覆盖。

6. 在快捷指令底部，点击 **匹配文本** 的结果变量，选择 **第一个匹配项**。

### 步骤 5 · 添加 URL 拼接与打开 App 操作

1. 点击 **添加操作**，搜索并选择 **URL**。
2. 在 URL 输入框中拼接：
   - 先输入 `pickupcode://show?code=`
   - 然后插入变量：选择上一步提取的 **第一个匹配项**
3. 点击 **添加操作**，搜索并选择 **打开 URL**。

进阶（可选）：在 URL 后面继续拼接 `&station=驿站名`（用"匹配文本"提取，正则见下表 R4）。不拼接时 App 显示"未知驿站"。

### 步骤 6 · 关闭"运行前询问"

1. 在自动化编辑页面，点击底部 **运行前询问** 开关，将其 **关闭**。
2. 系统弹出确认，选择 **不询问**（否则每次收到短信都要手动确认，失去自动化意义）。

### 步骤 7 · 保存并测试

1. 点击右上角 **完成**，保存自动化。
2. 测试：找一条历史快递短信，复制内容，用快捷指令"手动运行"测试提取是否正确、能否正常调起 App。

## 二、取件码正则规则速查（按需替换步骤 4 的正则）

| 规则 | 适用场景 | 正则表达式 |
| --- | --- | --- |
| R1 | 通用「取件码：XXXX」（冒号） | `取件码[：:]\s*([0-9\-]+)` |
| R2 | 通用「取件码 XXXX」（无冒号） | `取件码\s+([0-9\-]+)` |
| R3 | 丰巢/快递柜 | `(?:丰巢|快递柜).*?取件码[：:]?\s*([0-9\-]+)` |
| R4 | 驿站（连驿站名一起提取） | `取件码[：:]?\s*([0-9\-]+).*?(?:驿站|网点)[：:]?\s*([^\s,，]+)` |
| R5 | 短信写"验证码"但实为取件码 | `(?:取件|快递).*?码[：:]?\s*([0-9\-]+)` |
| R6 | 字母数字混合取件码（部分快递柜） | `取件码[：:]?\s*([A-Za-z0-9]+)` |

示例验证（App 端均已支持展示）：

- 「取件码：3-2-1056」→ `3-2-1056`（含横杠）
- 「取件码 884756」→ `884756`
- 「取件码：A3B5C7」→ `A3B5C7`（字母数字混合，用 R6）

## 三、URL 参数与编码

App 接收的完整 URL 格式：

```
pickupcode://show?code=<取件码>&station=<驿站名>&courier=<快递公司>&expiry=<ISO8601 过期时间>&note=<备注>
```

- `code` 必填；`station` 缺省显示"未知驿站"；`expiry` 支持 `2026-10-18T22:00:00+08:00` 或 Unix 秒级时间戳
- App 端同时兼容产品早期草稿的 `carrier`/`expire` 参数名
- 中文参数值需 URL 编码（快捷指令的「URL 编码」操作可自动处理），App 端自动解码

## 四、提取失败的兜底（建议配置）

在步骤 4 与步骤 5 之间加一个「如果」判断（快捷指令：搜索"如果"操作，条件设为「匹配文本」结果 为空）：

- **如果** 没有匹配到取件码 → **显示通知**："未识别到取件码，请手动复制"（不再继续打开 URL）。
- 同时避免 App 未安装时"打开 URL"报错中断。

## 五、配置检查清单

- [ ] 自动化已创建并启用
- [ ] 触发关键词已设置（至少包含"取件码"）
- [ ] 正则表达式能正确提取取件码
- [ ] URL scheme 拼接正确（`pickupcode://show?code=XXX`）
- [ ] "运行前询问"已关闭
- [ ] 手动测试通过

## 六、常见问题

- **没弹出灵动岛**：确认机型为 iPhone 14 Pro 及以上；其余机型看锁屏实时活动（下拉锁屏可见）。
- **短信触发了但 App 没打开**：检查 URL 是否为 `pickupcode://show?code=...`（注意 scheme 拼写）；确认 App 已安装。
- **取件码提取错误**：换用上表更合适的正则；含横杠的码确认正则里有 `\-`。
- **改了正则不生效**：自动化编辑后记得点"完成"保存。
