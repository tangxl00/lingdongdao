# 快捷指令配置指南（SHORTCUTS.md）

配合《此刻 App》使用：收到快递取件短信 / 火车票 / 机票邮件后，由「快捷指令自动化」自动调用本 App 的识别 Intent，内容自动出现在「此刻」，并在锁屏、灵动岛与主屏小组件常驻。**目标读者：普通 iPhone 用户，无需技术背景，按步骤照做即可。**

前提：iPhone 已安装"快捷指令"App（系统自带）；本 App 已按 README 第一章安装到手机。

---

## 一、7 步配置流程（短信自动添加）

### 步骤 1 · 打开快捷指令 APP

在桌面找到并打开 **快捷指令** App。

### 步骤 2 · 创建个人自动化

1. 点击底部 **自动化** 标签。
2. 点击右上角 **`+`**（新建自动化）。
3. 选择 **创建个人自动化**。

### 步骤 3 · 设置触发条件

1. 向下滚动，选择 **信息**。
2. 在"收到信息时"页面：
   - **信息包含**：输入 `取件码`（可再追加 `驿站`、`丰巢`、`快递柜`、`车次`、`航班` 等关键词，逗号分隔）。
   - **发送人**：选择 **任何人**。
3. 点击右上角 **下一步**。

> 建议策略：至少包含"取件码"即可覆盖 90% 以上场景；火车票 / 机票短信可另建一条自动化。

### 步骤 4 · 调用「此刻」的识别 Intent

1. 点击 **添加操作**。
2. 搜索 **此刻**（本 App 的名称），选 **识别文本**（`RecognizeTextIntent`）。
3. 在"文本"参数里插入变量：**快捷指令输入**（或 **获取文本** 的结果）。
4. 其余参数（快捷指令 ID / 版本 / 模式）保持默认即可。

> 也可以完全跳过本步骤，改用第 5 步的 URL 方案 —— 两者等效。

### 步骤 5 · （替代方案）URL 拼接与打开 App

1. 点击 **添加操作**，搜索并选择 **URL**。
2. 在 URL 输入框中拼接 `floaty://add?text=` + 变量（短信正文）。
3. 点击 **添加操作**，搜索并选择 **打开 URL**。

进阶（可选）：识别成功后自动把内容推上锁屏 —— 再加一步 **在锁屏显示**（`ShowLockScreenBoardIntent`）。

### 步骤 6 · 关闭"运行前询问"

1. 在自动化编辑页面，点击底部 **运行前询问** 开关，将其 **关闭**。
2. 系统弹出确认，选择 **不询问**。

### 步骤 7 · 保存并测试

1. 点击右上角 **完成**，保存自动化。
2. 测试：找一条历史短信，用快捷指令"手动运行"测试能否识别并入库。

## 二、邮件自动添加

1. 快捷指令 → **自动化** → 新建 → 选 **邮件**。
2. 触发条件：**收件人 / 邮件包含** 填 `取件码`、`订单`、`行程`、`车次`、`航班` 等。
3. 添加操作 → 选 **获取最新邮件内容**（取正文）或 **获取邮件内容**。
4. 添加操作 → **此刻** → **识别文本**，把上一步结果插入"文本"参数。
5. 关闭"运行前询问" → 完成。

> 邮件正文常带签名与免责声明，建议先在 App 内「设置 → 识别模板 → 测试识别」里验证命中效果。

## 三、锁屏看板控制（快捷指令 / 小组件）

本 App 提供以下 Intent，可在快捷指令里直接调用：

| 想做的事 | 选这个 Intent | 参数怎么填 |
| --- | --- | --- |
| 在锁屏显示看板 | **在锁屏显示** | 类型填逗号分隔串（`pickup,todo`，留空=全部）；过滤方式选「仅显示所选 / 排除所选 / 不显示」 |
| 不在锁屏显示 | **不在锁屏显示** | 类型留空 = 隐藏全部 |
| 切换锁屏看板开关 | **切换锁屏看板** | 模式选「切换显示 / 显示 / 隐藏」 |
| 结束锁屏显示 | **结束锁屏显示** | 无参数 |
| 切换页面 | **切换页面** | 偏移 = 翻页步长，默认 1 |
| 切换项目 | **切换项目** / **切换当前项目** | 偏移 = 聚焦步长，默认 1（在当前页内移动） |
| 标记完成 | **标记完成**（完成当前聚焦项）/ **完成内容** / **完成取件** | 后两个需填「内容 ID」（UUID） |
| 勾选待办子项 | **勾选子项** / **勾选看板子项** | 填「子项 ID」+「内容 ID」（均为 UUID） |

> **识别类 Intent 的批量输入**：AppIntents 不支持数组参数，所以
> **识别文本** 用单个「文本」参数，**识别文本列表** 用「文本列表」参数，
> **每行一段**（`---` 会被忽略）。

## 四、语音短语（Siri / 快捷指令）

本 App 注册了 5 个短语：

- "添加取件码到 此刻" / "用 此刻 记取件码"
- "添加待办到 此刻" / "用 此刻 记待办"
- "添加火车票到 此刻" / "用 此刻 记火车票"
- "添加机票到 此刻" / "用 此刻 记机票"
- "用 此刻 识别文本"

> 长按 Home 键 / 双击侧边键 → **添加快捷指令** 里也能直接挑这 5 个动作。

## 五、URL 契约速查

```
floaty://show?kind=<pickup|todo|train|flight>&title=<主标题>&station=<地点>&courier=<快递公司>
              &from=<起点>&to=<终点>&departure=<ISO8601>&arrival=<ISO8601>&expiry=<ISO8601>
              &seat=<座位>&car=<车厢>&gate=<检票口/登机口>&terminal=<航站楼>&note=<备注>
floaty://done?id=<UUID>
floaty://add?text=<原始文本>&source=<sms|mail|notification|clipboard>
```

- 兼容旧契约：`pickupcode://show?code=...&station=...`
- 时间字段接受 ISO 8601（`2026-10-18T22:00:00+08:00`）与 Unix 秒/毫秒时间戳
- 中文参数值需 URL 编码（快捷指令的「URL 编码」操作可自动处理）

## 六、识别模板正则速查

内置 12 条模板（中英文），可在「设置 → 识别模板」里查看与编辑。常用捕获组：

| 捕获组 | 含义 | 适用类型 |
| --- | --- | --- |
| `code` | 取件码 | 取件码 |
| `place` | 取件地点 | 取件码 |
| `due` / `deadline` | 截止时间 | 取件码 / 待办 |
| `train` | 车次 | 火车票 |
| `flight` | 航班号 | 机票 |
| `from` / `to` | 起点 / 终点 | 火车票 / 机票 |
| `departure` / `arrival` | 出发 / 到达时间 | 火车票 / 机票 |
| `departureTerminal` / `arrivalTerminal` | 航站楼 | 机票 |
| `seat` / `car` / `gate` | 座位 / 车厢 / 检票口·登机口 | 火车票 / 机票 |
| `headline` | 待办标题 | 待办 |
| `note` | 备注 | 待办 / 取件码 |

内置模板示例：

| 模板 | 匹配样例 |
| --- | --- |
| 取件码（英文） | `Your parcel is at Front Desk. Pickup code: A-8-9527.` |
| 取件码（中文） | `您的包裹已到丰巢，取件码：A-8-9527，请及时取走` |
| 取件码（含截止时间） | `取件码：886677，请于 2026-10-24 18:00 前取走` |
| 火车票 | `Train G9527, departs Oct 24 14:30, Beijing South → Shanghai Hongqiao, car 5 seat 12A, ticket gate B12.` |
| 火车票（中文） | `G9527次，北京南-上海虹桥，10月24日14:30 开，05车12A号，检票口B12` |
| 机票 | `Flight CA9527, departs Oct 24 08:15, PEK T3 → PVG T2, seat 32A, gate C12.` |
| 机票（中文） | `CA9527，PEK T3 飞 PVG T2，10月24日08:15 起飞，座位32A，登机口C12` |
| 待办 | `Remember to pick up the package this afternoon. Note: at the door` |
| 待办（中文） | `记得下午去取快递，备注：放在门口` |

自己写模板时：**至少要有一个命名捕获组**提供主标识（取件码 `code` / 车次 `train` / 航班 `flight` / 待办 `headline`），否则该模板不会命中。

## 八、常见问题

- **没弹出锁屏卡片**：确认机型为 iPhone 14 Pro 及以上；其余机型看锁屏实时活动（下拉锁屏可见）；检查 iOS 设置 → 本 App → 实时活动 是否开启。
- **短信触发了但没入库**：打开 App →「设置 → 识别模板 → 测试识别」粘贴短信原文，看是否命中；不命中就在该页新建模板（可用「匹配文本」的正则做参考）。
- **只想要自己用的模板**：关闭「设置 → 自动添加 → 内置取件识别」，并删除不需要的内置模板。
- **改了正则不生效**：自动化编辑后记得点"完成"保存；App 内模板保存后立即生效。
- **内容重复出现**：同类型同标题且未完结的内容会自动合并更新，不会重复堆积。
